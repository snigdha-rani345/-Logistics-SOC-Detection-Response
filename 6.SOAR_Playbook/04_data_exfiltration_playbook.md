# SOAR Playbook 4: Data Exfiltration Response

## Step 1: Triage
- What data was taken?
- How much data? Which server?

## Step 2: Contain
- BLOCK the destination IP / Domain
- DISABLE compromised account

## Step 3: Investigate
- How did attacker get in?
- Check logs for 30 days

## Step 4: Recover
- Patch the vulnerability
- RESET all admin passwords
- Inform Manager / Legal team

## Step 5: Lessons Learned
- What to improve next time?
